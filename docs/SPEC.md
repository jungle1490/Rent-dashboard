# SPEC — Rent-dashboard

## What this is
定期從 591 抓台北市租屋物件，放進一個可以多重複選、排除已看、標記新上架的自製介面。給自己找房用。

## MVP scope (M1)
- [x] 每 30 分鐘自動抓台北市物件（GitHub Actions），電腦關機也照跑
- [x] 多條捷運線同時選，可再細選到站；離站距離上限
- [x] 多行政區複選，顯示每區筆數
- [x] 租金區間（可切換「含額外費用的總額」）；租金已包含項目（管理費／水費／網路…）可篩
- [x] 坪數、房型、類型、出租方（屋主／仲介）、標籤（可養寵物、可開伙…）
- [x] 收藏、排除（排除後不再出現）
- [x] 新上架（跨輪比對）、降價、已下架標記
- [x] 詳細面板：相簿、完整欄位、到 591 的連結；上一頁關閉回看板
- [ ] 滑卡模式：只限新上架＋未看過，套用目前篩選；右滑收藏、左滑跳過（仍在「全部」可見）、可返回上一張（T-001）
- [ ] 手機版：篩選收成抽屜、底部工具列、單欄卡片（T-002）
- [ ] 推上 GitHub 並開始自動更新（T-003）

## Non-goals (things we explicitly do NOT build)
- 不抓 591 物件詳細頁（屋況說明、格局圖、聯絡方式），這些一律連回 591
- 不做推播通知（舊的 Telegram 版本在 `legacy/`，已棄用）
- 不做跨裝置同步（收藏／排除／已看存瀏覽器本機）— 除非之後明確要求
- 不做帳號、不做多人共用
- 不爬 591 以外的來源

## Success criteria
- 開網頁 2 秒內看到清單，「資料更新於」在 1 小時內
- 選 3 條捷運線＋2 個行政區＋租金區間，結果數隨條件單調收斂，且每張卡片都符合條件
- 滑過／排除的物件不會再進滑卡佇列；排除的不出現在「全部」，跳過的仍出現
- 連續 7 天 Actions 無失敗；591 改版時抓取中止而不覆蓋舊資料
